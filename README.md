# 🚀 Interactive Kinetic Typography with Matter.js

An interactive physics-based typography web application built with **JavaScript (ES6)** and **Matter.js**. This project transforms dynamic text into rigid physical bodies that react to gravity, user interaction, collisions, and external forces.

---

## ✨ Features

- **Real-Time Text Generation:** Type any word to spawn canvas-rendered physical letter bodies.
- **Mouse Drag & Physics:** Grab, fling, and toss letters across the screen.
- **Explosion Force Effect:** Apply sudden impulse forces to scatter letters into the air.
- **Responsive Screen Boundaries:** Built-in collision walls that keep elements within view across different screen sizes.

---

## 🛠️ Tech Stack

- **HTML5 & CSS3** (Flexbox, Backdrop Blur)
- **Vanilla JavaScript (ES6)**
- **[Matter.js](https://brm.io/matter-js/)** (2D Physics Engine)
- **Google Fonts** (*Space Grotesk*)
